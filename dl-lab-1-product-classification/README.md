# dl-lab-1-image-classification

Решение соревнования **Kaggle DL. Lab 1. Image Classification**. Задача — многоклассовая классификация изображений фруктов и овощей по 15 классам.

В решении обучаются две архитектуры — **ConvNeXt V2 Tiny** и **EVA-02 Small**. Для каждой модели используется 5-fold cross-validation, двухэтапное fine-tuning, взвешенный Focal Loss, CutMix/MixUp и Test-Time Augmentation. Финальный результат получен взвешенным ансамблем двух моделей с коэффициентами, подобранными по OOF-предсказаниям.

## Содержимое репозитория

- `train-eva02-small.ipynb` — подготовка данных, обучение EVA-02 Small на пяти фолдах, анализ качества и генерация submission без TTA и с 8 TTA-вариантами.
- `train-convnextv2-tiny.ipynb` — подготовка данных, обучение ConvNeXt V2 Tiny на пяти фолдах, анализ качества и генерация submission без TTA и с 8 TTA-вариантами.
- `test-ensemble-tta-best-params.ipynb` — OOF-инференс обеих архитектур с TTA, расчёт метрик и матриц ошибок, оптимизация весов ансамбля методом Nelder–Mead и финальный inference на тестовой выборке.

## Общая схема обучения

Обе модели обучаются по одинаковой двухэтапной схеме.

### Stage 1 — Head Warmup

- backbone заморожен;
- обучается только классификационная голова;
- 8 эпох;
- оптимизатор `AdamW`;
- scheduler `OneCycleLR`;
- `FocalLossHard` с весами классов и `label_smoothing=0.05`;
- MixUp и CutMix не применяются;
- сохраняются веса с максимальной `val_accuracy`.

### Stage 2 — Full Fine-Tuning

- загружается лучший checkpoint Stage 1;
- размораживается вся модель;
- для backbone и head используются разные learning rate;
- scheduler `CosineAnnealingLR`, `eta_min=1e-7`;
- CutMix или MixUp применяется с вероятностью 0.5;
- `CUTMIX_ALPHA=0.4`, `MIXUP_ALPHA=0.3`;
- используется `FocalLossSoft`, поддерживающий soft labels;
- сохраняется лучший checkpoint по `val_accuracy`.

### Функция потерь

Используется Focal Loss с параметрами:

| Параметр | Значение |
|---|---:|
| `gamma` | 2.0 |
| Сглаживание весов классов `alpha` | 0.5 |
| Label smoothing `epsilon` | 0.05 |
| Средний вес класса | 1.0 |

`FocalLossHard` используется для обычных целочисленных меток на Stage 1 и validation. `FocalLossSoft` используется на Stage 2 для soft labels после MixUp/CutMix.

### Общие аугментации

- горизонтальное и вертикальное отражение;
- поворот на 90°;
- `ShiftScaleRotate`;
- изменение яркости, контраста и gamma;
- CLAHE;
- небольшое изменение hue, saturation и value;
- перспективные и нелинейные деформации;
- Gaussian Blur, Motion Blur или Gaussian Noise;
- CoarseDropout, GridDropout или PixelDropout;
- ImageNet-нормализация.

Обучение и inference выполняются с автоматической смешанной точностью через `torch.amp.autocast` и `GradScaler`.

## 3. Weighted Test-Time Augmentation

Для каждой архитектуры создаются восемь детерминированных вариантов изображения:

```text
4 геометрии × 2 масштаба = 8 TTA-вариантов
```

Геометрии:

1. исходное изображение;
2. horizontal flip;
3. vertical flip;
4. horizontal + vertical flip.

Для каждой геометрии рассчитываются два масштаба:

- полное изображение — вес 1.00;
- центральный crop с последующим resize — вес 0.25.

Softmax-вероятности TTA-вариантов усредняются с учётом этих весов, затем усредняются вероятности пяти фолдов.

| Модель | Размер | Crop margin | Интерпретация |
|---|---:|---:|---|
| ConvNeXt V2 Tiny | 288 × 288 | ≈14 px | 5% от размера входа |
| EVA-02 Small | 280 × 280 | 14 px | ровно один patch с каждой стороны |

Количество forward-pass:

| Схема | Пассов на изображение |
|---|---:|
| Одна модель одного фолда без TTA | 1 |
| Одна архитектура, 5 folds, без TTA | 5 |
| Одна архитектура, 5 folds, 8TTA | 40 |
| Две архитектуры, 5 folds, 8TTA | 80 |

## 5. Оптимизация ансамбля

Вероятности моделей объединяются линейно:

```text
p_ensemble = w_convnext · p_convnext + w_eva · p_eva
```

Коэффициенты подбираются на OOF-предсказаниях методом `Nelder-Mead`. Целевая функция — максимизация `F1 macro`.

| Модель | Оптимальный вес |
|---|---:|
| ConvNeXt V2 Tiny | 0.5349 |
| EVA-02 Small | 0.4651 |

Результат оптимизации:

| Решение | OOF F1 macro | OOF Accuracy |
|---|---:|---:|
| ConvNeXt V2 Tiny | 0.9578 | 0.9614 |
| EVA-02 Small | 0.9497 | 0.9542 |
| **Взвешенный ансамбль** | **0.9602** | **0.9635** |

Ансамбль увеличил `F1 macro` на 0.0025 относительно лучшей отдельной модели.

Для дополнительной проверки в ноутбуке строится зависимость OOF F1 macro от доли ConvNeXt в ансамбле на сетке от 0 до 100%.

## 6. Финальный inference

Финальный submission рассчитывается следующим образом:

1. Для каждого тестового изображения строятся 8 TTA-вариантов.
2. Для каждого варианта выполняется inference пятью моделями ConvNeXt V2 Tiny.
3. Вероятности TTA и фолдов усредняются.
4. Аналогично рассчитываются вероятности пяти моделей EVA-02 Small.
5. Вероятности архитектур объединяются с весами `0.5349 / 0.4651`.
6. Выбирается класс с максимальной итоговой вероятностью.

```text
ConvNeXt: 5 folds × 8 TTA = 40 forward-pass
EVA-02:   5 folds × 8 TTA = 40 forward-pass
Итого:                         80 forward-pass на изображение
```

Время финального inference для 2503 изображений в сохранённом запуске — 40 минут 42 секунды.
